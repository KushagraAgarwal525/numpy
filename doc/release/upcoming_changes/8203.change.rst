``histogram`` Freedman-Diaconis estimator no longer OOMs on tiny IQR
--------------------------------------------------------------------
``numpy.histogram`` and ``numpy.histogram_bin_edges`` with ``bins='fd'``
no longer attempt to allocate astronomical numbers of bins when the
interquartile range is a tiny nonzero value (for example from
floating-point noise). The FD width is floored using the same
square-root heuristic as ``bins='auto'``, and all automatic estimators
are subject to a size-based safety cap on the bin count.
